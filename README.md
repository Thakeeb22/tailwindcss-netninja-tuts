# Tailwind CSS Learning Project

A learning repository following **Net Ninja's Tailwind CSS tutorials**. This project demonstrates core Tailwind CSS concepts and principles using vanilla HTML, CSS, and JavaScript with a modern build setup.

## 📚 About This Project

This repository contains tutorial code built while learning Tailwind CSS from Net Ninja's tutorial series. The goal is to master utility-first CSS design and build responsive, modern web interfaces without relying on JavaScript frameworks.

**Tech Stack:**
- 🎨 **Tailwind CSS** – Utility-first CSS framework
- 📝 **HTML** – Semantic markup
- ⚙️ **Vanilla JavaScript** – DOM manipulation and interactivity (no frameworks)
- 📦 **Node.js & npm** – Build tools and package management

## 🎯 What You'll Find

This repository includes:
- Tutorial code and implementations
- Responsive component examples
- Interactive UI patterns built with Tailwind utilities
- Best practices for organizing utility-first CSS
- Real-world styling scenarios
- Configured Tailwind CSS build setup

## 🚀 Getting Started

### Prerequisites
- Node.js and npm installed
- A modern web browser
- A code editor (VS Code recommended)
- Basic knowledge of HTML, CSS, and JavaScript

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Thakeeb22/tailwindcss-netninja-tuts.git
cd tailwindcss-netninja-tuts
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open `index.html` in your browser or view the compiled output from the `public` directory

### Build for Production
```bash
npm run build
```
